# Design System: 핑고핑고

## Overview

**Creative North Star: "함께 펼친 지도"**

친구 넷이 테이블에 지도 한 장을 펼쳐 놓고, 각자 포스트잇을 붙이고, 갈리는 곳에 동그라미를 친다. 화면의 주인공은 그 지도다. 바텀시트·버튼·칩은 지도 위에 얹은 메모처럼 절제하고, 핀과 의견만 또렷하게 보인다.

- **진행자 원칙:** 지도 위에서 이 체계는 조용한 진행자처럼 행동한다. 의견이 갈린 곳(반대 → 조율)을 먼저 드러내고, 지금 할 일 하나만 브랜드 파랑으로 강조한다.
- **핑고의 자리:** 핑고는 서비스의 안내자다. 안내·로딩·빈 상태·오류·AI 화면에 나온다(2026-10-19). AI가 만든 내용인지는 「AI」 배지와 올리기 전 후보의 핑고 핀이 알린다. 친근함은 핑고와 "~해요" 말투가 맡고, 화면 전체를 귀엽게 만들지 않는다.

밀도는 중간 이상이다. 시트 절반 높이에서 핀 3~4개와 각 반응 집계가 한 번에 읽혀야 한다. 장식보다 상태(의견 필요 / 완료 / 확정 / AI 후보)를 정확히 구분하는 데 힘을 쓴다.

**Key Characteristics:**
- 지도가 항상 떠 있고, UI는 시트 하나와 그 위에 따라붙는 지도 버튼·토스트뿐이다.
- 색은 영역으로 갈린다. UI는 파랑, 지도 위 핀은 빨강, 확정만 골드다.
- AI는 형태(올리기 전 후보의 핑고 핀)·톤(brand-50 면)·「AI」 배지로 구분한다. 지도에 올린 AI 추천 핀은 일반 핀과 같은 모양이다 — 모두의 핀이 된 뒤라서다. AI 표시는 핀 상세의 「AI」 배지와 근거가 맡는다.
- 반응은 기호 + 색 + 숫자로 함께 보여 준다. 색만으로 뜻을 전하지 않는다.

## Colors

파랑 217° 하나로 UI를 끌고 가고, 빨강·골드·반응 3색은 정해진 영역 밖으로 나가지 않는다.

### Primary
- **핑고 파랑** (brand-300): 면 전용이다. 핑고 모자·머리 핀, AI 영역 테두리에 쓴다. 흰 글자 대비가 2.2:1이라 글자 바탕으로 쓰지 않는다.
- **액션 파랑** (brand-600): 채움 버튼, 링크, 활성 탭, 선택 테두리, 지도 버튼 아이콘, 동선 경로선(4px)에 쓴다. 흰 글자 대비는 6.5:1이다.
- **선택 파랑** (brand-100 바탕 + brand-600 선 + brand-700 글자): 켜진 칩과 토글이다. 채우지 않는다.
- **AI 물** (brand-50): AI 후보 카드, 핑고 배너, 「의견 남기기」 칩 바탕이다.

### Tertiary
- **확정 골드** (confirmed-gold, 글자는 confirmed-mark 갈색): 확정 핀, 확정 리스트·동선 순서 번호, 「★ 확정 리스트에 넣기」(연골드 바탕 + 골드 테두리), 마킹된 장소 목록의 확정 카드(골드 테두리 + `tag-confirmed`)에만 쓴다.

### Neutral
- **잉크** (ink-900): 본문 글자다.
- **보조 글자** (ink-600 / ink-500): 부가정보와 비활성 탭에 쓴다. ink-500은 흰 바탕 대비 약 5:1이다.
- **희미한 색** (ink-400): 대비가 약 2.5:1이다. 아이콘·비활성 전용이고, 읽어야 하는 글자(집계 숫자·「(나)」·「(선택)」·글자 수)에는 쓰지 않는다. 글자 회색은 900 / 600 / 500 세 단계다.
- **선** (ink-200 hairline / ink-300 control): 카드 테두리와 입력 테두리다.
- **종이** (ink-50): 입구 화면의 페이지 배경이다.

### 핑고 경고 분홍
- **pingo-alert** (`#DC6A6A`, 캐릭터 시안 Alert Pink): 핑고 ALERT(의견 부족·주의)의 모자·머리 핀에만 쓴다. 글자·면·버튼에는 쓰지 않는다.

### Semantic
- **좋음** (good-bg / good-line / good-text), **조율·주의** (warn-*), **반대** (bad-bg / pin-red / bad-text): 배경·선·글자가 한 세트다. 선 색을 글자에 쓰지 않는다.

### Named Rules
**영역 분리 규칙.** 빨강 계열은 지도 위 핀과 반응 🚫, 되돌릴 수 없는 액션, 핑고 ALERT(모자·핀)에만 쓴다. 버튼·배지·면이 빨개지면 화면 전체가 경고처럼 보여서다. 입력 오류는 빨강이 아니라 주의색(warn-line 테두리 + warn-text 글자)이다.

**한 화면 한 채움 규칙.** 한 화면에 채운 버튼은 하나다. 나머지는 외곽선이나 글자 버튼으로 둔다.

**파랑은 할 일 규칙.** 초록·노랑·빨강은 반응의 뜻으로 이미 쓰고 있다. 그래서 "아직 의견을 안 남김" 같은 할 일 표시는 브랜드 파랑으로만 한다.

## Typography

**Body Font:** Pretendard Variable(dynamic subset, `src/index.css`). Figma 시안은 아직 Noto Sans KR이라 글자 폭이 조금 다르다.

**글자 크기는 rem으로 쓴다.** `text-[13px]` 같은 px 고정값은 사용자가 글자를 키워도 커지지 않아 위계가 뒤집힌다(150% 확대 점검, #308). 아래 px는 기본 16px 기준 값이다.

**Character:** 한 글꼴 가족 하나로 굵기 대비만으로 위계를 만든다. 제목도 같은 가족을 쓴다. 굵기는 700(제목·버튼) / 600(태그·켜진 칩·짧은 강조) / 500(탭 라벨·글자 버튼) / 400(본문) 네 단계다.

### Hierarchy
단계마다 클래스가 하나다(`src/index.css` `@theme`). 이 여덟 단계 밖의 크기(`text-lg`, `text-[…]`)는 쓰지 않는다.

| 단계 | 크기·굵기 | 클래스 | 쓰는 곳 |
|---|---|---|---|
| Page title | 24 / 700 | `text-2xl` | 입구 화면 제목(「내 지도」·「새 지도」) |
| Sheet title | 20 / 700 | `text-xl` · `ui/SheetTitle` | 시트 머리(「마킹된 장소」), 핀 이름, 검색 결과 머리, 모달 시트 제목 |
| Card title | 17 / 700 | `text-title` | 지도 카드·AI 후보 카드 이름, 확인 창 제목, 전체 화면 머리줄(근거 확인) |
| Button · Item title | 16 / 700 | `text-base` | 전폭 버튼(btn-lg), 목록의 핀 이름 |
| Section title | 14 / 700 | `text-sm font-bold` | 시트 안 구역 제목(「내 의견 선택」·「구성원」·「꼭 지켜야 하는 조건」) |
| Body | 13 / 400 | `text-body` | 칩, 이유 문장, 메타 줄, 시트 안 뒤로가기 |
| Caption | 12 / 400 | `text-xs` | 부가정보, 태그, 참여 집계(「2/4명이 의견을 남겼어요」는 700) |
| Label | 11 / 500 | `text-label` | 탭 라벨, 글자 수, 작은 안내(＊ 줄) |

- **입력칸은 16px다.** 아이폰 Safari는 16px보다 작은 입력칸에 포커스하면 화면을 확대해 지도 화면이 어긋난다. 검색창도 같다. 안내문(placeholder)은 ink-500이다.
- **예외:** 로그인 화면 워드마크 「핑고핑고」(30 / 800, brand-600)만 단계 밖이다. 로고 자리라서다.

### Named Rules
**Light 금지 규칙.** 300 굵기는 쓰지 않는다. 13px Light 회색 안내문은 읽히지 않는다.

## Layout

- **주 화면:** 393px 폭에서 지도 화면 좌우 여백은 16px, 입구 화면은 20px이다.
- **바텀시트:** 3단계다. 1단계는 손잡이 + 제목 줄만 보인다. 2단계는 시트 위끝이 화면 높이의 41%다. 3단계는 상단 39px까지 올라온다. 시트는 하단 탭(74px + 홈 표시줄) 위에서 멈춘다. 탭 막대가 커져도 시트 위끝은 그대로 두고 시트 높이를 줄인다.
- **핀 상세:** 2단계로 열리고, 내용을 끌어 올리면 3단계(의견 쓰기)로 자동 확장한다(#296). 2단계에서 「내 의견」 3버튼이 보이도록 순서는 [이름·참여율·반응 집계] → [내 의견·사유·등록] → [갈린 의견] → [아직 안 남긴 사람 한 줄]이다. 사진 칸은 두지 않는다 — 카카오 응답 저장 금지(#53)라 영원히 비어 있다. 자세한 정보는 메타 줄 끝 「카카오맵」 링크.
- **화면 단계:** 모바일(767px 이하) · 태블릿(768~1023px, Tailwind `md`) · PC(1024px 이상, `lg`) 셋이다(#603). 태블릿은 아래 데스크톱 배치를 그대로 쓰고 내용 패널만 360px로 좁힌다. 360은 모바일이 이미 맞춰 둔 가장 좁은 폭이라 패널 안 내용이 그대로 들어가고, 세로 태블릿에서 지도가 288 → 336px(768 기준)로 넓어진다. 세로 탭 줄은 머티리얼 디자인이 중간 폭에 권하는 방식과 같다. 로그인 화면은 태블릿부터 입구 카드다(#602).
- **데스크톱:** 넓은 화면(768px 이상, Tailwind `md`)은 왼쪽 480px(태블릿 432px) + 오른쪽 지도 영역이다(#351·#338). 왼쪽 480px는 맨 왼쪽 세로 탭 줄 72px + 높이 전체 내용 패널 408px다(네이버 지도처럼). 탭 줄은 탭 3개를 세로로 쌓고, 칸마다 아이콘 + 11/500 라벨(라벨 그대로, AI도 같은 모양), 활성은 brand-50 면 + brand-600이다. 내용 패널은 위에서부터 헤더(‹ · 지도 제목 ▾ · 구성원) · 검색창 · 탭 내용이고, 탭 내용은 패널 안에서 평범하게 스크롤한다 — 단계·손잡이·끌기·자동 확장이 없다. 탭 줄과 패널은 지도 위에 떠 있지 않아서 그림자 없이 ink-200 오른쪽 선으로 나눈다. 패널 오른쪽 가장자리 세로 가운데의 « 손잡이로 내용 패널만 접고(탭 줄은 남고 나머지는 지도) » 로 편다. 접힌 채 탭·핀·검색 번호를 누르면 패널이 다시 열린다. 지도 영역 왼쪽 위에는 카테고리 칩(마우스는 좁으면 줄바꿈, 터치는 모바일처럼 옆으로 밀기, #603)과 연결 끊김 띠, 우하단에는 지도 버튼 묶음(16px 여백), 바닥 가운데에는 토스트가 온다. 지도를 옮기는 보정(검색 결과·최근 핀·전체 핀 보기)은 이 지도 영역 기준이다.
- **넓은 화면 헤더의 ‹ 와 지도 제목:** ‹ 는 패널 안 이전 화면(핀 상세 → 목록, 후보 상세 → 추천 결과, 검색 장소 → 검색 결과, 근거 확인 → AI 추천)이고, 돌아갈 곳이 없으면 보이지 않는다. 패널 안에는 ‹ 를 따로 그리지 않는다 — 한 패널에 ‹ 가 둘이면 어느 쪽이 지도를 나가는지 헷갈린다. 지도 밖으로 나가는 길은 지도 제목 메뉴(▾)다: 내 지도 목록(지금 지도에 ✓) · 「새 지도 만들기」 · 「내 지도 목록」. 내 지도 목록 화면은 처음 지도를 고를 때만 거친다. 오른쪽 구성원 버튼은 바닥 시트가 아니라 버튼 바로 아래에 붙는 지도 정보 메뉴(반경 16, 딤 없음)를 연다.
- **지도 위:** 위에는 뒤로가기 · 프로필 · 검색창 · 카테고리 칩만 둔다. 오른쪽 아래에는 지도 버튼 묶음이 시트 윗변을 따라 오르내린다. 넓은 화면은 위 데스크톱 줄을 따른다.
- **내 지도 목록(넓은 화면):** 가운데 480px 띠 대신 최대 1024px 틀(좌우 32px)에 지도 카드를 2열(1024px 이상 3열) 격자로 깐다. 페이지 바탕(ink-50)은 화면 전체에 깐다. 「새 지도 만들기」(채움, 화면에 하나)는 헤더 오른쪽 계정 버튼 옆이고, 제목 아래에 「지도 n / 상한」을 적는다(모바일도 같다). 상한은 목록 응답의 `limit`만 쓰고 코드에 숫자로 두지 않는다(#599, #623). 값이 오기 전에도 그 줄 높이를 비워 둬서 목록이 밀리지 않게 한다. 상한까지 차면 「새 지도 만들기」를 비활성으로 두고 「다른 지도를 나가거나 삭제하면 다시 만들 수 있어요」를 그 줄 끝에 붙인다(모바일도 같다). 계정은 바닥 시트가 아니라 계정 버튼 아래에 붙는 메뉴(반경 16)다. 카드는 마우스를 올리면 테두리만 brand-300으로 바뀐다.
- **간격 리듬:** 목록 카드 사이 10px, 칩 사이 8px, 핀 항목 안 12px, 지도 카드 안 16px이다.

**지도 집중 규칙.** 지도를 끄는 동안 검색창과 지도 버튼은 0.15초에 사라진다. 멈추면 0.8초 뒤 0.3초 동안 다시 나타난다.

**지도 버튼 자리 규칙.** 지도 버튼 묶음(44×3)은 시트 윗변 12px 위에 붙어 오르내린다. 상단 UI(검색창·칩·연결 띠) 아래끝 + 4px보다 위로 올라가야 하면 숨긴다 — 3단계·모달·높은 시트·작은 화면(아이폰 SE 2단계). 코드는 실제 공간을 재서 자동으로 숨긴다(#308). 넓은 화면은 지도 영역 우하단에 고정이고 모달일 때만 숨긴다(#338).

## Elevation & Depth

목록과 카드는 평평하다. 테두리만 쓰고 그림자는 없다. 그림자는 지도 위에 떠 있는 것에만 준다. 기준색은 모두 잉크(rgba(20,22,31,α))다.

### Shadow Vocabulary
- **떠 있는 컨트롤** (`shadow-float`, `0 2px 8px rgba(20,22,31,.12)`): 지도 버튼 묶음, 검색창, 상단 원 버튼, 지도 위 카테고리 칩, 하단 AI 원, 패널 손잡이다. Tailwind 기본 `shadow`·`shadow-sm`·`shadow-md`는 순수 검정이라 쓰지 않는다.
- **시트** (`shadow-sheet`, `0 -2px 12px rgba(20,22,31,.08)`): 바텀시트 윗변이다.
- **확정 핀** (`0 2px 4px rgba(0,0,0,.28)`): 흰 테두리 3px와 함께 바다 위 가시성을 맡는다. 빼지 않는다.

**시트 안 그림자 금지 규칙.** 시트 안의 틀에는 그림자를 넣지 않는다. 시트를 올리면 회색 줄로 보인다.

## Shapes

- **반경 단계:** 태그 6(`rounded-sm`) → 컨트롤·작은 버튼 8(`rounded-md`) → 카드·버튼·입력칸·지도 버튼 12(`rounded-xl`) → 시트·확인 창 16(`rounded-2xl`) → 칩 알약(`rounded-full`)이다. 코드는 `--radius-*`를 이 값으로 고정했다(#299). `rounded-lg`도 12지만 이름을 하나로 두려고 `rounded-xl`만 쓴다. 맨 `rounded`(4)는 쓰지 않는다.
- 카드는 핀 항목·AI 카드·지도 카드·핑고 배너·초대 카드 모두 12 하나다(Figma의 10·12·14 혼재를 모음).
- **아이콘을 담는 면:** 원이 아니라 둥근 사각형이다(지도 버튼). 상단 뒤로가기·프로필만 원이다.

## Motion

움직임은 무엇이 어디서 왔는지를 알려 줄 때만 쓴다. 시트는 아래에서, 넓은 화면 패널은 옆에서 나오는 식이다. 꾸미려고 움직이지 않는다(#595).

- **시간:** 작은 것(딤·확인 창·핀·목록)은 0.2초, 시트·패널처럼 화면 끝에서 들어오는 큰 것은 0.3초다. 0.5초를 넘기지 않는다.
- **곡선:** ease-out(`cubic-bezier(0, 0, 0.2, 1)`) 하나다. 빠르게 나와서 천천히 멈춘다.
- **거리:** 제자리에서 나타나는 것은 8px 이하로 움직이고, 크기는 95%에서 시작한다. 화면 밖에서 들어오는 시트만 제 높이만큼 움직인다.
- **동작 줄이기:** 기기에서 동작 줄이기를 켜면 모든 움직임을 끈다(`prefers-reduced-motion`, Tailwind `motion-reduce:`).
- **닫힐 때:** 모달 시트만 0.2초 동안 닫힘 효과를 준다. 좁은 화면에서는 아래로 내려가고, 넓은 화면의 가운데 창은 흐려진다. 사용자가 닫을 때(딤·Esc·끌어 내리기)만 효과가 나고, 효과가 끝난 뒤 `onClose`가 불린다. 「완료」처럼 부모가 바로 빼서 닫는 경우와 확인 창은 바로 사라진다. 빨리 사라져야 다음 동작이 막히지 않는다.
- **핑고 예외:** 핑고의 들썩임(AI가 찾는 중)과 걷기(응답 기다림)는 끝날 때까지 반복한다. 꾸밈이 아니라 "지금 일하는 중"을 알리는 상태 표시라서 0.5초 상한 밖이다. 로그인 화면의 날기(`fly`, 들썩임 + 망토 펄럭임)는 첫인상 그림이라 예외로 둔다(#640). 고른 AI 후보 핀을 끌어안는 핑고(`hug`)는 머리 뒤에서 0.3초에 올라오고 풀리면 0.2초에 내려간다. 머리를 감싼 손은 0.2초 뒤 나타난다. 그 핀은 한 번 튄다(`pin-bounce`, 0.4초). 지도 위 여러 후보 중 어느 것을 골랐는지 알리는 표시라 예외로 둔다. 고른 검색 결과도 한 번 튀지만 핑고는 붙지 않는다. 첫 로그인 온보딩 장면(`WelcomeScene`)은 핑고가 그 장의 기능을 쓰는 모습(핀 꽂기 · 좋음·반대 누르기 · 의견을 모아 후보 찾기 · 확정과 동선)을 3~4초 주기로 되풀이한다. 기능을 보여 주는 그림이라 예외로 둔다(2026-10-31). 단계 사이 움직임은 0.2~0.3초 등장 클래스와 transition만 쓰고, 움직임 줄이기면 그 기능을 다 쓴 그림에서 멈춘다. 그 밖에 핑고를 뛰거나 떠다니게 하지 않는다 — 결과 도착 때 한 번 뛰던 것은 꾸밈이라 뺐다(#634).
- **끌어 내리기:** 좁은 화면의 모달 시트는 손잡이 줄(높이 28px)을 끌면 손가락을 따라 내려간다. 80px를 넘기고 놓으면 닫히고, 덜 끌면 제자리로 돌아간다. 내용은 끌리지 않는다. 긴 목록(지역 고르기)의 스크롤과 부딪히기 때문이다.

**등장 클래스.** 새로 만들지 말고 `src/index.css`의 클래스를 붙인다. 동작 줄이기 처리가 들어 있다.

| 클래스 | 효과 | 쓰는 곳 |
|---|---|---|
| `enter-fade` | 0.2초 페이드 | 모달·확인 창의 딤, AI 추천 결과 도착 |
| `enter-pop` | 0.2초 페이드 + 95%→100% | 확인 창 상자 |
| `enter-drop` | 0.2초 페이드 + 위 8px에서 내려옴 | 방금 생긴 지도 핀 |
| `enter-sheet` | 0.3초 아래에서 올라옴(넓은 화면은 `enter-pop`과 같음) | 모달 시트 |
| `pin-bounce` | 0.4초 1→1.4→1.15→1.25배, 끝을 붙든 채 튀고 1.25배에 머묾 | 고른 검색 결과 핀 |
| `pingo-rise` · `pingo-sink` | 0.3초 아래에서 올라옴 · 0.2초 아래로 들어감(자기 상자 밖은 잘림) | AI 후보 핀을 끌어안는 핑고 |
| `pingo-hands` | 0.2초 뒤 0.15초 페이드 | 그 핑고가 핀 머리를 감싼 손 |

**처음 한 번 규칙.** 같은 것이 다시 보일 때는 움직이지 않는다. 지도를 처음 열 때·카테고리 칩을 바꿀 때 나타나는 핀은 그대로 서 있고, 방금 생긴 핀(10초 안)만 한 번 떨어진다. AI 결과는 실행마다 처음 한 번만 나타나고, 후보 상세에서 돌아올 때는 그대로다.

**상태 바뀜.** 위치·높이가 바뀌는 것(시트 단계, 패널 접기)은 등장 클래스가 아니라 `transition-[속성] duration-300 ease-out motion-reduce:transition-none`으로 옮긴다. 지도를 끄는 동안 사라지는 것은 위 "지도 집중 규칙"을 따른다.

## Components

### Buttons
버튼은 **색 하나 + 크기 하나**다. 높이·글자 크기·반경을 그 자리에서 덧쓰지 않고, 폭(`w-full`·`flex-1`)과 바깥 여백만 준다.

| 색 | 모양 | 쓰는 곳 |
|---|---|---|

### Chips · Tags
- **칩(`chip`)** — 누르는 알약이다(카테고리·지역·사유·「동선 보기」). 13/400, 높이 32, 누르는 곳 44. 켜짐은 `aria-pressed`로 정한다: brand-100 + brand-600 테두리 + brand-700 글자 600. 기본은 흰 바탕 + ink-200 테두리 + ink-700 글자다. 그림자는 지도 위에 떠 있을 때만(`CategoryChips floating`) 준다. 조건이 안 돼 못 누르는 칩(확정 2곳 미만의 「AI 코스 짜기」·「동선 보기」)은 `aria-disabled`로 비활성 모양(ink-50 면 + ink-500 글자)을 하되 눌리게 두고, 누르면 이유를 토스트로 알린다.
- **사유 칩:** 같은 모양에 `chip-against`를 더한다. 반대 사유를 고르면 반대 세트(bad-bg + pin-red 테두리 + bad-text)다. 파랑으로 켜지 않는다(#299).
- **태그(`tag` + `tag-*`)** — 누를 수 없는 짧은 표시다. 12/600, 반경 6. `tag-neutral`(방장·지역) · `tag-ai`(AI) · `tag-good`/`tag-warn`/`tag-bad`(준비 완료·조건 체크) · `tag-confirmed`(「✓ 확정됨」, 연골드 + 갈색 글자). 흰 글자를 선 색(good-line·warn-line) 위에 얹지 않는다 — warn-line 위 흰 글자는 3.5:1이라 작은 글자 기준(4.5:1)에 못 미친다.

### Cards / Containers
- **핀 항목:** 흰 바탕, ink-200 테두리, 반경 12, 안쪽 12다. 의견을 남긴 핀도 흰 바탕이다. 회색 면은 비활성처럼 읽힌다. 의견이 필요한 핀만 brand-600 1.5px 테두리 + 「의견 남기기」 칩이다(#299). 확정된 핀은 골드(pin-confirmed) 1.5px 테두리 + `tag-confirmed` 「✓ 확정됨」이고, 내 의견이 없어도 이쪽이 먼저다(#859).
- **AI 후보 카드:** brand-50 바탕 + brand-300 테두리다. 이유 · 조건 체크 칩 · 구성원 충족 · 출처를 빼지 않는다(가드레일 5).
- **입구(로그인 화면):** 위에서부터 워드마크(`Wordmark`, 높이 40) + 부제 → 지도 그림 위를 날아가는 핑고(`fly`, 지도에 그림자) → 한 줄 안내 → 카카오·게스트 버튼 → 구분선 → 「핑고핑고에서 누릴 수 있는 기능이에요」 기능 목록(쓰는 순서대로 핀·말풍선·반짝임·별 아이콘, brand-50 둥근 사각형 32 + brand-600 아이콘 16. 같은 체크 반복과 초록은 쓰지 않는다 — 초록은 좋음·조건 충족 전용) → 약관 동의 줄이다. 넓은 화면(768px 이상)은 종이 배경 가운데 흰 바탕 + ink-200 테두리 입구 카드(반경 16, 최대 폭 400, 안쪽 좌우 32·위아래 40, 그림자 없음)이고 순서는 같다. 1024px 이상은 두 칸이다 — 왼쪽에 워드마크(높이 56)·부제·핑고 그림을 크게(핑고 1.35배), 오른쪽 입구 카드에 안내 줄부터 약관 줄까지 둔다. 휴대폰은 카드 없이 흰 화면 전체를 쓰고 약관 줄은 화면 맨 아래다. 약관 동의 줄은 12/400 ink-500이고 「이용약관」만 brand-600 굵게 + 밑줄이다. 누르면 「이용약관 목록」 모달 시트(이용약관·개인정보처리방침·위치기반서비스 이용약관, 모두 필수)가 뜨고 줄마다 문서를 연다. 법적 고지라 이 줄만 「동의하는 것으로 간주됩니다」처럼 ~됩니다체로 쓴다(#602).

### Inputs / Fields
- **입력칸(`field` · `ui/TextField`):** 흰 바탕, ink-300 테두리, 반경 12, 높이 48, 글자 16이다. 글자가 있을 때만 오른쪽에 ✕(`ClearButton`)와 글자 수가 보인다. 포커스하면 테두리가 brand-500으로 바뀌고 2px 포커스 링이 붙는다. 날짜·여러 줄 입력도 같은 `field` 틀이다.
- **오류:** `aria-invalid`를 켜면 warn-line 테두리가 되고, 문구는 warn-text다.

### Navigation
- **하단 탭:** 74px + 홈 표시줄이다. 세 탭은 화면을 3등분한 칸의 가운데다. 좌우는 24px 선 아이콘 + 11/500 라벨(활성 brand-600, 비활성 ink-500)이다. 가운데는 AI 원(48px) + 「AI 추천」 라벨이다. 비활성은 흰 바탕 + brand-300 2px 테두리 + 파란 얼굴, 활성만 brand-600 채움 + 흰 얼굴이다. 원이 작아서 몸 전체 대신 시안의 단순화 로고(`PingoMark`, 얼굴만)를 쓴다. 한 화면 한 채움 규칙을 지킨다(#299). 넓은 화면 탭 줄도 같은 얼굴이다.
- **검색창:** 글자는 16/400(입력칸 규칙 — 아이폰 확대 방지), 안내문은 ink-500(대비 약 5:1)이다. 지도를 끄는 동안 사라지고, 그동안은 눌리지 않는다.
- **상단:** 모바일 좌상단 ‹(흰 원)는 내 지도 목록이다. 넓은 화면 패널 헤더의 ‹ 는 패널 안 이전 화면이고, 지도 바꾸기는 지도 제목 메뉴다(Layout 절). 우상단은 지도 정보·구성원 버튼으로, 구성원 아이콘 + 인원 수를 보여 준다(이니셜 원은 계정처럼 읽혀서 바꿈, #351). 보이는 원은 32px, 누르는 영역은 44px이다.

### 지도 핀 (Signature)
- **일반·AI 추천:** pin-red 실선 2.5px이다. 속은 참여율만큼 ink-200 → pin-red를 oklch로 섞는다. 머리 가운데에 테두리보다 어두운 빨간 점(`--pin-dot`, 지름 6.4/24)을 넣어 핀처럼 읽히게 한다. 회색 속·빨강 속 어디서나 보인다.
- **AI 추천은 올리면 일반 핀이다:** 「지도에 올리기」를 하면 모두의 핀이라 일반 핀 모양·참여율 색으로 그린다. AI 표시는 핀 상세의 「AI」 배지·근거·출처가 맡는다(가드레일 5). 점선 모양은 없앴다.
- **AI 후보(올리기 전) — 핑고 핀:** AI 추천 탭에서만, 요청한 사람의 화면에만 그린다. brand-600 물방울 + 흰 테두리 2 + 그림자, 머리에 흰 핑고 얼굴(`PingoMark` 도형, `ui/pingoMark`)이다. 카드와 같은 순위 숫자는 오른쪽 위 배지(흰 바탕 + brand-600 1.5px 테두리, 11/700 brand-700)다. 올린 후보는 핀으로 떠 있어서 그리지 않는다. 카드를 누르거나 이 핀을 누르면 서로 같은 후보가 골라진다(카드는 brand-600 테두리, #843). 고른 핀은 한 번 튀어 1.25배·흰 후광·이름 말풍선으로 머물고, 핑고(`hug`)가 머리 뒤에서 올라와 위에서 머리를 끌어안는다 — 몸은 핀 뒤, 손은 머리 어깨 앞이다. 다른 후보를 고르거나 빈 곳을 누르면 핑고는 머리 뒤로 내려간다. **핑고는 AI에만 나온다** — 검색 결과에는 붙이지 않는다(2026-10-31, PRODUCT.md 「핑고가 나오면 AI가 말한 것이다」).
- **선택된 핀:** 상세를 연 핀은 1.25배·흰 후광·맨 위로 올리고 아래에 이름 말풍선을 띄운다(#308).
- **고르면 줌인:** 핀·AI 후보·검색 결과를 고르면(목록이든 지도든) 지도가 그곳으로 부드럽게 옮긴 뒤 레벨 3까지 0.3초 동안 확대한다. 이미 더 가까우면 옮기기만 한다. 모바일은 2단계 시트 위 보이는 영역 가운데로 온다. 움직임 줄이기 설정이면 애니메이션 없이 바로 간다(#843).
- **검색 결과:** 핀이 아니라 잠깐 보는 자리라 물방울이 아닌 빨간 원(지름 28, pin-red + 흰 테두리 2 + 그림자)에 흰 카테고리 아이콘을 넣고 아래 짧은 꼬리 끝이 좌표다(네이버 검색 핀처럼). 아이콘은 음식점 utensils · 카페 coffee · 관광지 camera · 숙소 bed-double · 기타 map-pin(lucide 선 경로, `pinMarker`의 표 하나). 지도에는 숫자를 적지 않는다. 고르면 한 번 튀어 1.25배·흰 후광·이름 말풍선으로 머문다. 핑고는 붙지 않는다(AI가 아니라서).
- **빈 곳을 누르면 풀린다:** 지도 빈 곳을 누르면 고른 것이 풀린다 — 핀 상세(마킹·확정 탭)는 목록으로, 검색 장소는 결과 목록으로 돌아가고, AI 후보는 카드·핀 강조만 풀린다. 지도는 움직이지 않는다. 끌고 놓는 것은 누르기가 아니다.
- **누르는 영역:** 보이는 핀은 30×38이지만 누르는 영역은 44×44다.
- **확정:** 골드 채움 + 흰 테두리 3px + 그 바깥 갈색 1px(confirmed-mark) + 그림자(0 2px 6px .35) + 갈색 ♥다. 밝은 땅 위에서 흰 테두리만으로는 1.2:1이라 갈색 선이 가시성을 맡는다(#299).

### 빈 결과 (AI 0곳)
- 「반경 넓히기」가 유일한 채움 버튼이다. 사람이 누르는 버튼이라 가드레일 4와 맞는다. 「근거 고치기」는 외곽선이고, 「직접 찍기」는 brand-600 글자 링크다(#299).
- 서버가 카카오맵 검색 링크를 주면(#798) 두 버튼 아래 같은 묶음에 `ExternalSearchLink`(`btn-outline btn-lg`, 두 칸 폭)를 둔다. 결과가 적을 때는 후보 목록 아래 `btn-outline btn-md`, 추천 준비에서 그 지역에 정예 장소가 없을 때는 추천 버튼 위 `Notice`(「이 지역은 아직 핑고 추천 장소가 없어요」) 안 `btn-outline btn-sm`이다. 추천 버튼은 막지 않는다. 기준 숫자(몇 곳 미만)는 화면에 적지 않고 링크가 있는지만 본다.

### 핑고
캐릭터 시안(`PINGO_캐디.pdf`, 2026-10-19)의 평면 2D 기본형이다. 흰 몸 + 핑고 파랑 모자·머리 핀 + ink-300 외곽선이다. 시트·패널 안에서는 3D 렌더가 겉돌아서 평면만 쓴다. 표정은 그 화면의 상황으로 고른다.

| `mood` | 상황 | 쓰는 곳 |
|---|---|---|
| `default` | 기본·안내 | 추천 준비, 후보 상세, 빈 상태 |
| `wave` | 정리를 마침(시안 「결정했어요!」) | AI가 정리한 조건 |
| `happy` | 추천 완료(시안 JUMP) | 결과 N곳 |
| `thinking` | AI가 결과를 찾는 중, 제자리에서 들썩인다 | 추천 찾는 중 |
| `walk` | 응답을 기다리는 로딩(시안 WALK CYCLE), 뒤뚱뒤뚱 걷는다 | `PingoLoading` |
| `sorry` | 찾던 게 없음(시안 NO SUGGESTION) | 결과 0곳, 검색 0곳, 끊긴 초대 |
| `error` | 실패(시안 ERROR) | 추천 실패, 지도를 불러오지 못함 |
| `alert` | 의견 부족·주의(시안 ALERT, 모자·핀이 `pingo-alert`) | 추천 준비에서 준비된 카테고리가 하나도 없을 때 |
| `hug` | 고른 AI 후보 핀의 머리를 위에서 끌어안음(웃는 눈, 30px, 팔 없음 — 머리를 감싼 손은 핀이 그림, 시안에 없는 자세) | 지도 위 고른 AI 후보 |
| `fly` | 첫인상 — 망토를 두르고 주먹을 앞으로 뻗어 날아간다. 손에 든 것은 없다(핀을 쥐면 머리 핀·지도 핀과 겹쳐 산만했다)(시안에 없는 자세, 기본형을 40° 기울임). 망토는 brand-600, 끝이 펄럭인다 | 로그인 화면 지도 그림 위 |

- **첫 로그인 온보딩(`/welcome`):** 장면 단계마다 그 순간의 상황으로 고른다. 핀을 들고 있을 땐 `wave`, 꽂거나 좋음을 누르거나 후보·확정이 나오면 `happy`, 후보를 찾는 동안은 `thinking`, 그 밖엔 `default`다(`features/onboarding/WelcomeScene`).
- **고개 내밀기(`peek`):** 카드 윗변에 손을 걸치고 고개만 내민다(시안 「BOTTOM NAVIGATION」). 안내·참여 요청 카드(온보딩)에 쓴다.
- **로딩:** 응답이 1초 안에 오면 아무것도 띄우지 않는다. 핑고가 잠깐 번쩍이면 오히려 거슬린다. 들어설 모양을 아는 목록은 `CardSkeleton`이다.
- **움직임:** 들썩임(AI가 찾는 중)·걷기(응답 기다림), 로그인 화면 날기의 들썩임·망토 펄럭임뿐이다. Motion 절 「핑고 예외」다. 움직임 줄이기 설정이면 멈춘다.
- **핑고가 나오지 않는 곳:** 꼭 지켜야 하는 조건 삭제 경고, 지역 분리 경고, 「메뉴 확인 필요」(가드레일 8) 같은 안전·되돌릴 수 없는 경고다. 캐릭터가 붙으면 가볍게 읽힌다(`docs/design/colors.md` 3층).

### AI 코스 (#683)

확정 탭 「AI 코스 짜기」 칩이 `ModalSheet` 하나를 연다. 한 시트 안에서 진입(요청 한 줄 + 「코스 짜기」) → 진행 → 결과가 바뀐다. AI가 짠 것이라 머리는 `AiHeader`(핑고 + 「AI」)다. 지도와 확정 리스트는 바꾸지 않고 결과는 요청한 사람에게만 보인다. 시간은 어디에도 쓰지 않는다 — 날짜별 순서와 구간 이동 분뿐이다.

- **작업 기록 줄(`WorkLog`)** — 흰 면 + ink-200 테두리(`ring-1`) 카드 한 줄이다. 윗줄 12px에 「단계(600 ink-900) · 역할 · 누가 칩」, 아랫줄 13px에 문장. 섞인 단계의 원문(`by_detail`, 「모델 → 코드」)은 윗줄 끝에 ink-500 보조 글씨다. 줄은 위에서 아래로 쌓이기만 하고(키는 줄 번호) 앞 줄은 바뀌지 않는다. 진행 중엔 `aria-live="polite"`다. 질문 줄도 이번엔 버튼 없이 기록으로만 둔다.
- **첫 「이해」 줄은 AI 카드** — `ai-card` 계열(brand-50 면 + brand-300 1.5px 테두리 + 반경 12)에 제목 「이렇게 이해했어요」. 문장 앞에 같은 말이 오면 한 번만 보인다. `steps`가 비어 있는 처음 몇 초는 `PingoLoading` 「요청을 읽고 있어요」.
- **역할·누가 표시** — 역할(해석·지휘·계산·검증·결정)은 글자만, 「누가」만 `tag`다. 색과 글자를 같이 쓴다: AI = `tag-ai`(brand-600 면), 코드 = `tag-neutral`(ink 회색), 사람 = `tag-neutral` + 사람 아이콘(주황 `tag-warn`은 조건 체크의 주의 색이라 쓰지 않는다 — 사람이 한 단계는 경고가 아니라 결정이다). 색만으로 전하지 않는다.
- **결과** — 머리(`AiHeader`, 결과 한 줄) → 「요청한 것」(목표마다 `tag-good` 지킴 · `tag-bad` 못 지킴 · `tag-neutral` 확인할 수 없어요) → 「반영하지 못했어요: 「…」」 → 날짜별 카드 → 「지키지 못한 조건」(`tag-bad`) → 「코스에서 빠진 장소」 → 「작업 기록 보기」(`btn-link`, 펼치면 `WorkLog`). 확정 리스트가 바뀌었으면(`stale`) 맨 위에 `Notice` + `btn-outline btn-sm` 「다시 짜기」. 실패는 `AiHeader mood="sorry"` + 한 문장 「코스 짜기가 중간에 끊겼어요」(INTERRUPTED·ENGINE_ERROR 모두) + 「다시 짜기」(`btn-primary`). 진행 중 조회가 실패하면 진행 화면 밑에 `ErrorText` + `btn-outline` 「다시 불러오기」. 이미 짜는 중인 코스(409)로 들어오면 맨 위에 `Notice` 「이미 짜는 중인 코스가 있어서 그걸 보여 드려요」. 날짜 서수는 열넷째까지 쓴다.
- **날짜별 카드(`DayCard`)** — 흰 면 + ink-200 `ring-1` + 반경 12 + 패딩 12. 제목 「첫째 날 · 10.3 (토)」(16/700). 장소는 번호 원(ink-100 면, 20px) + 이름(13/600)이고, 장소 사이엔 ink-200 세로선과 구간 문구(12 ink-500)다 — 도보는 「도보 N분」 글자만, 대중교통은 `tag-neutral` + 버스 아이콘 「대중교통 약 N분」이고 옆에 `btn-link` 「대중교통 길찾기」(카카오맵 `by/traffic`, 출발→도착)가 붙는다. 제목 밑엔 하루 합계 「도보 X분 · 대중교통 약 Y분」(12 ink-500, 0인 쪽은 뺌), 카드 맨 밑엔 이어지는 도보 구간마다 「카카오맵에서 길찾기」(`by/walk`, 앞 7곳까지, 경로가 둘 이상이면 「도보 길찾기 N」)다. 링크는 새 탭이고 우리 핀의 이름·좌표만 담으며(#53), 좌표를 모르는 구간엔 링크를 두지 않는다. 영업 여부를 모르는 장소엔 `tag-warn` 「? 영업 확인 필요」. 이동 분은 직선거리 어림이라고 카드 밑에 한 줄 밝힌다.
- **날짜별 경로선(지도)** — 결과의 「날짜별 순서」 밑 `btn-outline btn-md` 「지도에서 날짜별로 보기」를 누르면 시트를 닫고 확정 탭 시트를 절반(2단계)으로 둔 채 지도에 날짜마다 선을 긋는다. 색(`--course-day-1~3`: brand-600 · 보라 · 청록, 흰 바탕 대비 4.5:1 이상)과 선 모양(실선 · 긴 점선 · 짧은 점선 · 긴 점선+점)을 다른 주기로 돌려 열둘째 날까지 겹치지 않고, 색을 구분하기 어려워도 모양으로 가른다. 선은 5px로 「동선 보기」(4px)와 핀 테두리보다 굵다. 순서 번호 원은 그날 색 면 + 흰 숫자(그날 방문 순서), 구간 알약은 흰 면 + 그날 색 테두리·글자다(「도보 N분」 · 「대중교통 약 N분」). 좌표를 모르는 장소는 선에서 빠지고, 한 곳뿐인 날은 선 없이 번호 원만 있다. 지도를 고정하지 않는다.
- **코스 범례(`CourseMapLegend`)** — 코스를 지도에 보이는 동안 확정 탭 머리 밑에 붙는다. 흰 면 + ink-200 `ring-1` + 반경 12. 「AI 코스를 지도에 보여 주고 있어요」(12/600) + 날짜마다 선 견본(24px, 그날 색·모양) + 「첫째 날 · 10.3 (토)」(12 ink-700), 오른쪽에 `btn-neutral btn-sm` 「끄기」. 「동선 보기」와 같은 자리에 그어서 둘은 함께 켜지지 않는다 — 코스를 보이면 동선 보기를 끄고, 동선 보기를 켜면 코스가 꺼진다. 다른 탭에선 선을 그리지 않는다.

### 핑고 AI 조언 (#516, #536)

계획 보조 에이전트(docs/agent-v2.md 16절)의 자리다. 에이전트는 아무것도 직접 하지 않는다 — 버튼은 사람이 원래 하던 동작의 지름길이다. 문장은 모두 서버가 렌더하고 화면은 숫자나 슬롯을 만들지 않는다.

- **버튼(`AgentButton`)** — 마킹 탭 지도 왼쪽 아래, 오른쪽 지도 버튼 묶음과 같은 줄이다. 모바일은 시트 윗변 12px 위에 붙어 오르내리고 숨는 조건(3단계·모달·좁은 화면)과 지도를 끌 때 흐려지는 것도 지도 버튼과 같다. 넓은 화면은 지도 영역 왼쪽 아래 16px 고정. 모양은 지도 버튼과 같은 흰 면 + `shadow-float` + 반경 12, 높이 44, `PingoMark` 24 + 「핑고 AI 조언」(14/700 brand-600). 새 제안을 아직 안 봤으면 오른쪽 위에 brand-600 점(12px, 흰 2px 테두리, 할 일은 파랑). 모드가 꺼져 있으면 점만 숨긴다.
- **시트** — `ModalSheet`(지도 화면이라 `fullWidth`). 제목 줄 오른쪽에 `Switch`(모드). 꺼져 있으면 「꺼져 있어요 · ○○님이 껐어요」 한 줄만. 제안이 없으면 `AiHeader` 「지금은 따로 드릴 제안이 없어요」.
- **제안** — `AiHeader`(서버 제목, 「구성원 모두에게 같은 제안이 보여요」) → 「확인된 것」(is_guess=false) → 「어디서 갈리나요」(의견 갈림만: 충돌 종류 한 줄 + 축마다 카드 한 칸, 「♥ 좋음 쪽 · 원함 2」 good-text, 반대 기호 + 「반대 쪽 · 원하지 않음 1」 bad-text) → 「AI 조언」(is_guess=true, 줄마다 `tag-neutral` 「추정」) → 버튼(첫 버튼만 `btn-primary btn-md`, 나머지 `btn-outline btn-md`, 전폭) → `btn-text` 「이 제안 닫기」(지도 단위라 모두에게서 닫힌다). 구성원 의견 인용(quote)은 따옴표 + ink-100 면이고 누가 썼는지 붙이지 않는다.
- **우리 조건 요약(#589, `SummarySection`)** — 제안 아래 ink-100 선으로 나눈 구역. 카테고리가 둘 이상이면 `chip`(aria-pressed)으로 고른다. 칸은 흰 면 + ink-200 `ring-1` + 반경 12, 칸 이름 12/700 ink-600 + 줄마다 13/400 — 「지키려는 조건」·「겹치는 선호」(「매운 곳 제외 · 1명」), 「갈리는 선호」(「체인점 · 원함 1 / 피함 1」), 「더 적어 주면 반영돼요 · n건」, 「추천이 거르지 않아요 · n건」. 이름 없이 개수만이고 빈 칸은 그리지 않는다. 추천 대상 카테고리면 맨 아래 `btn-outline btn-md` 「이 조건으로 ○○ 추천 받기」(제안의 채움 버튼과 겹치지 않게 외곽선).
- **추천 막힘 조언(#589, `RunAdvice`)** — AI 추천 결과의 깔때기 줄 아래, 핑고 면(`--pingo-bg`) + 반경 12 + 패딩 12. 머리 「더 많이 추천받으려면」(`PingoMark` 20 + 14/700), 문장(추정이면 `tag-neutral` 「추정」), 버튼 `btn-outline btn-sm`(「반경 넓히기」는 화면의 확인 창 버튼 그대로, 근거 확인). 기다리는 동안 ink-50 자리(높이 64)만, 대상이 아니거나 실패면 아무것도 없다. 0곳 화면은 아래에 같은 버튼이 있어 문장만 보인다.
- **실패** — 다른 구성원이 먼저 처리했으면(409) 토스트 「다른 구성원이 먼저 처리한 제안이에요」 후 상태를 다시 받는다. 버튼이 이어 간 기존 동작이 막히면(준비가 풀림 등) 토스트 「상황이 바뀌었어요」.

### 연결 상태
- 연결이 끊기면 지도 위에 띄우지 않고 시트 윗변에 붙는 얇은 띠로 알린다. 넓은 화면은 시트 윗변이 없어서 지도 영역 왼쪽 위 칩 아래에 떠 있는 띠(반경 12, 그림자)로 둔다(#338). 띠는 ink-100 바탕 + warn-line 아이콘 + ink-700 글자이고, 문구를 자르지 않는다. 노랑 면은 확정 골드와 겹쳐서 쓰지 않는다(#299).

### 모달
- 딤은 `--scrim` 32% 하나다. 포커스를 시트 안에 가두고, 닫으면 연 버튼으로 돌려준다(#299).
- 넓은 화면에는 바닥 시트를 쓰지 않는다. 버튼에서 여는 계정·지도 정보는 그 버튼 아래 메뉴(확인 창이 떠 있는 동안은 닫지 않음)이고, 그 밖의 모달 시트(지역 고르기 등)는 화면 가운데 창(최대 440px, 반경 16, 손잡이 없음)이다(#600).
- 좁은 화면(768px 미만)의 모달 시트는 입구 화면(내 지도·새 지도)에서 본문 단과 같은 최대 480px로 가운데에 뜬다. 지도 화면은 뒤의 지도 시트가 전체 폭이라 모달 시트도 전체 폭이다(`fullWidth`). 744px 같은 태블릿 세로에서 둘이 어긋나지 않게 하려는 것이다(#605).

### 토스트
- **모양:** toast 82% + 배경 흐림 12, 흰 글자, 반경 12다.
- **위치:** 시트 윗변 12px 위 가운데, 최대 361px이다. 지도 버튼 묶음과 가로로 겹치면 묶음 위로 올린다. 올리면 상단 UI를 덮게 되면 올리지 않고 폭을 버튼 왼쪽 − 8px까지로 줄여 두 줄로 쓴다(단어 단위 줄바꿈, #308). 넓은 화면은 지도 영역 바닥 16px 위 가운데이고, 버튼 묶음과 겹치면 올리지 않고 줄이기만 한다(#338).
- **동작 글자:** 흰색 굵게 + 밑줄(「되돌리기」·「다시 시도」).
- **시간:** 3초(동작이 있으면 5초)다.

## Do's and Don'ts

### Do:
- **Do** 화면을 만들기 전에 「컴포넌트 목록」을 먼저 본다. 맞는 부품이 없으면 부품부터 만들고 목록에 올린다.
- **Do** 색은 역할 토큰(`--action-fill`, `--text-secondary`…)으로 부른다. 원시 값(`--brand-600`)을 컴포넌트에서 직접 부르지 않는다.
- **Do** 반응은 기호 + 색 + 숫자로 보여 주고, 내 반응은 그 반응 색 칩에 "· 나"를 붙인다.
- **Do** 상단 원형 버튼을 포함한 모든 터치 대상을 최소 44×44px로 잡는다. 보이는 원이 32px이면 히트 영역을 넓힌다.
- **Do** 참여율 핀 아래에 「N/M명이 의견을 남겼어요」를 함께 둔다. 색 단계만으로는 구분이 안 된다.

### Don't:
- **Don't** shadcn 기본 `--primary`(거의 검정)를 버튼·핀에 쓰지 않는다. 브랜드 파랑과 핀 빨강이 정본이다.
- **Don't** 구성원별 색을 쓰지 않는다. 아바타는 회색 면 하나다.
- **Don't** "마킹됨" 배지, "내 선택: ○○" 배지, 범례 한 줄 설명을 넣지 않는다.
- **Don't** 이모지(📅 💬 👥)를 아이콘 대신 쓰지 않는다. lucide(Calendar · MessageSquare · Users)를 쓴다. 🚫는 화면에서 lucide Ban(`ui/AgainstMark`)으로 그리고 뜻은 옆 글자 「반대」가 전한다. ♥ △ ?는 글자로 둔다.
- **Don't** 통통 튀는 바운스·출렁이는 스프링, 목록 항목이 하나씩 순서대로 뜨는 효과, 반짝임·떠다니기 같은 꾸밈 움직임을 넣지 않는다. 탭 전환·♥/🚫 반응처럼 자주 누르는 동작에는 등장 효과를 걸지 않는다(#595).
- **Don't** 버튼에 `py-3`·`text-sm`·`rounded-md`를 덧써서 크기를 바꾸지 않는다. 크기는 `btn-lg`/`md`/`sm` 중 하나다.
- **Don't** 확정 해제를 빨강으로 칠하지 않는다. 일상 동작이라 중립 글자 버튼이다. 밀어서 나오는 「빼기」도 ink-600 바탕 + 흰 글자다(#299).
