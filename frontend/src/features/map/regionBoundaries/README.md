# 시·도 경계

AI 추천 탭 지도에 여행 지역 경계를 그리고, 추천 원이 지역 밖인지 본다(`../regionGeo.ts`).

- 파일 이름은 통계청 시·도 코드다(2018). 라벨 ↔ 코드 표는 `features/maps/regions.ts`의 `REGION_CODES`.
- 내용은 `[다각형, ...]`, 다각형은 `[외곽, 구멍, ...]`, 고리는 `[[위도, 경도], ...]`(소수 4자리, 약 10m)다.
- 외곽은 반시계, 구멍은 시계 방향으로 맞췄다. 바깥 어둡게(넓은 사각형에 지역을 구멍으로 뚫음)가 채움 규칙과 상관없이 맞게 그려진다.
- 지도 지역 하나만 필요할 때 불러온다(`import.meta.glob` 지연 로딩). 첫 화면 번들에는 들어가지 않는다.

## 출처

- 통계청 SGIS 센서스용 행정구역경계(2018), [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)의
  `kostat/2018/json/skorea-provinces-2018-topo-simple.json`(간소화본)을 변환했다.
- 원 저장소 표기: KOSTAT 자료는 「Free to share or remix」. 출처는 통계청으로 적는다.
- 2018 자료라 이름이 「강원도」「전라북도」다. 코드(32, 35)로 맞춰서 지금 이름(강원특별자치도, 전북특별자치도)과 상관없다.

## 다시 만들 때

TopoJSON의 arcs를 풀어(transform으로 좌표 복원, 음수 번호는 뒤집기) 시·도마다 고리를 잇고,
소수 4자리로 반올림해 연달아 같은 점을 지운 뒤 방향을 위처럼 맞춘다. 변환 스크립트와 원본은 저장소에 두지 않는다.
