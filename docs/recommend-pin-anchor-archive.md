# 추천 위치 기준 — 교체 전 로직 기록 (핀 기반 앵커)

이 문서는 기록용이다. 해석·평가를 적지 않고, 시험 기록에서 수치와 환경을 **원문 그대로** 발췌했다.
교체 이유와 새 기준은 이슈 #1331이 정본이다.

## 이 보존본의 기준
- 태그 `legacy/recommend-pin-anchor`, 브랜치 `archive/recommend-pin-anchor`(수정하지 않는다).
- 기준 커밋: `d95ad97` (develop, 2026-11-04 11:29, PR #1324 병합 직후, PR #1333·#1335 병합 직전). 이 문서는 그 위의 커밋 하나다.
- 위치 기준: 지도에서 그 카테고리의 좌표 있는 공개 핀들(`recommend/flows.py` `_default_circle_and_anchors`)이 앵커다. 핀을 기본 반경×2 이내 연결로 묶어(`_clustered_regions`, `common/geo.py` `cluster_points`) 무리마다 지역을 만들고, 무리 안 핀마다 기본 반경 원의 합집합에서 후보를 DB(`ST_DWithin`)로 조회한다(#1252, PR #1262).
- 기본 반경: 음식점·카페 도보 15분, 관광지 도보 25분. 반경 넓히기 상한: 음식점·카페 30분, 관광지 45분(`docs/constraints.md`).
- 상위 3곳 선택: 점수 → 구성원 충족 조건 수(#1288, PR #1290) → 아직 안 뽑힌 동네 → 앵커 핀 거리 평균(`recommend/core.py` `select_top_candidates`).
- 반대 사유: 취향 반대는 감점, 접근성(`accessible`)·붐비는 대형(`is_crowded_large`)은 후보 제거(#1253, PR #1258).
- 자동 테스트 기록: PR #1262 본문 「pytest -q: 5258 passed, 9 deselected」, PR #1258 본문 「전체 `pytest -q`: 5252 passed, 9 deselected, 1 xfailed」.
