# 실행 순서 초안

이슈 본문의 "선행: #N" 표기를 모아 만든 순서 초안이다. **담당자 배정은 팀 몫으로 남겨둔다** — 이 문서는 "무엇을 먼저 해야 다른 걸 막지 않는지"만 정리한다. 최신 상태는 `gh issue list`가 정본이고, 이 문서는 2026-09-03 시점 스냅샷이다.
