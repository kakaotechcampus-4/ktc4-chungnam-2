# 체인(`franchise`) 재판정과 추천 시험 — 2026-10-27 ~ 10-28 (데이터 담당)

환경: 앱 = develop(로컬 :8000) · DB = 로컬 개발 DB(정예 규칙) · 모델 = `gpt-6-luna`(추천 시 사유 해석) · 판정 = 엘리스 Claude Sonnet 5.5 · 실행 = 데이터 담당 로컬 스크립트. 판정값은 시험 중에만 DB에 넣고 끝난 뒤 원래 값으로 복원했다.
목적: "체인점은 별로예요"가 제대로 동작하도록 `franchise`를 참/거짓 둘 다 확정한다.

## 배경
- 기존 규칙: 6개 지역 인허가에서 '브랜드 ○○점' 이름이 합계 20곳 이상 · 3개 지역 이상인 브랜드(전국 기준)만 참, 나머지는 모름. `docs/constraints.md`는 "거짓은 만들지 않는다".
- 0·1·3·4차에서 체인 싫어 사유가 모름 때문에 거르지 못했다.

## 1단계 — Sonnet 개별 판정(전국 기준)
- 서울 정예 음식점·카페 3,035곳을 이름·주소로 "전국 어디서나 가는 체인인가" 판정.

| | yes | no | unsure |
|---|---|---|---|
| 음식점(당시 모름 1,058) | 11 | 542 | 505 |
| 카페(당시 거짓 1,571) | 36 | 824 | 711 |
| 당시 참(음식점 301 / 카페 105) | 7 / 82 | 164 / 11 | 130 / 12 |

- 목록이 놓친 체인 47곳(아티제 20곳, 프롬하츠커피, 빕스, 서가앤쿡 등).
- 한계: unsure 45%. 기존 참 175곳(창고43, 두껍삼, 명동교자, 왕비집 등 서울 소수 브랜드)이 no — 목록 기준과 "전국 체인" 정의가 어긋남. 모델 기억에만 의존.
- 시험(66개, yes → 참, no → 거짓, unsure 그대로): 상위 3곳이 바뀐 시나리오 2개, 체인 거부 시나리오 후보 27곳 중 체인 0곳(unsure 13곳).

## 2단계 — 기준 변경(팀 합의): 서울 매장 수 5곳 초과 브랜드만 참, 나머지는 모두 거짓

판정 방법
1. 서울 정예 음식점·카페 + 인허가 커버리지 이름 전체(약 10.4만)에서 '브랜드 ○○점'은 브랜드로, 아니면 이름 전체(법인 표기·괄호·공백 제거)로 묶어 매장 수를 센다.
2. 지점명 매장만으로 5곳을 넘으면 체인(682개 브랜드).
3. 이름 전체가 같아서 5곳을 넘은 브랜드는 흔한 상호(전주집 26곳, 시골집 22곳, 사랑방 18곳)일 수 있어 Sonnet에 brand / generic을 물음: brand 318, generic 260, unsure 79.
4. unsure 79개와 경계 브랜드 11개는 데이터 담당이 직접 판정(체인 33, 아님 57). 직접 판정이 Sonnet보다 우선.
5. 정예 이름이 키로 안 잡히면 체인 브랜드로 시작하는지 봄(아티제 서울스퀘어 → 아티제, 3자 이상).
