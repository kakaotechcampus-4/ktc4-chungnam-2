# AI 추천 품질 시험 0차 — 2026-10-08 (데이터 담당)

환경: 앱 = 당시 develop · DB = 로컬 시연 DB(시험 중 음식점을 새 정예 파일로 교체) · 모델 = `gpt-6-luna`(실제 호출, 약 30회) · 실행 = 로컬 평가 스크립트(저장소 밖).
목적: 모델이 사유 글을 라벨 키(`fact_key`)로 제대로 바꾸는지, 그 키로 추천이 제대로 걸러지고 순위가 매겨지는지.

## 방법
- 사유 해석만 따로: 흔한 문장 40개, 헷갈리는 문장 20개(줄임말·부정·한 문장에 조건 두 개), 같은 문장 20번 반복, 실제 추천 흐름 28번.
- 추천 흐름: 동네 5곳(명동, 종로·인사동, 홍대, 강남역, 성수) × 사유 7가지, 구성원 2명이 ♥·🚫를 남기고 추천을 끝까지 실행. 모델 대신 정답 키를 넣은 **고정 모드**와 **실제 모델 모드**를 같이 돌렸다.

## 결과

| 시험 | 결과 |
|---|---|
| 흔한 문장 40개 | 40개 맞음 |
| 헷갈리는 문장 20개 | 16개 맞음 |
| 같은 문장 20번 반복 | 1~2번은 키 없이 돌아옴 |
| 실제 추천 흐름 28번 | **7번(25%) 키 없이 돌아옴** |

| 사유 | 걸러진 정도 | 상위 3곳 |
|---|---|---|
| 한식 말고 | 동네마다 51~121곳 빠짐 | 한식 없음 |
| 매운 거 못 먹어요 | 10~16곳 빠짐 | 매운 가게 없음 |
| 초밥 좋아해요 | 선호라 거르기 없음 | 명동은 3곳 모두 일식 아님 |
| 너무 비싸요 | 0곳 | 효과 없음(가격 기준 칸 없음) |
| 주차가 안 돼서 불편해요 | 4~23곳 빠짐 | 주차 불가 없음, 일부 모름 |
| 체인점은 별로예요 | 4~56곳 빠짐 | 3곳 모두 체인 여부 모름 |
| 갑각류 알러지 있어요 | 전부 빠짐 | 모든 동네 0곳 |

고정 모드 실격 위반 0건. 반경 안 후보는 명동 약 190곳, 강남역 약 88곳, 성수 약 20곳.

## 발견
- **D0-1 키 누락**: 키 없이 돌아온 사유는 오류가 아니라 정상 응답으로 처리돼 거르기에 아무 영향이 없다(성수 "갑각류 알러지" 무시 → 감자탕집 추천, 종로 "한식 말고" 무시 → 한식집 추천).
- **D0-2 사유 한 줄 = 조건 하나**: "매운 거랑 해산물 둘 다 안 돼요"에서 해산물이 빠짐. 모델에 카테고리를 주지 않아 음식점 사유에 관광지 키가 붙기도 함.
- **D0-3 순위가 ♥ 핀 특징에 끌려감**: ♥한 가게의 체인·기름짐·넓음·주차 라벨이 각각 1점 선호가 되어 직접 쓴 "초밥 좋아해요"가 밀림.
- **D0-4 참만 있는 라벨**: 갑각류·`franchise`는 거짓이 없어 알러지면 항상 0곳, 체인 싫어는 늘 모름. 인도 음식점이 양식으로 잡히는 등 음식 종류 오류.
- **D0-5 문구**: "선호 충족: 양식 … (0/1명)"처럼 충족했다면서 0명.
- 참고: `temperature=0`을 시험했으나 이 모델은 기본값만 받음.

## 이어진 수정
- 시연 DB 음식점을 정예 파일(1,217곳)로 교체: 매운맛·기름짐 확정 50% → 100%, 가격대 7% → 94%, 주차 11% → 65%.
- 사유 해석: 입력에서 키 없는 사실 빼기(#410), 사유 하나에서 조건 여러 개(#419).
- D0-3·D0-5는 1·2차에서 다시 측정해 결정(2차 기록 참고).
