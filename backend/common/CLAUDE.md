# backend/common

루트 문서를 먼저 읽는다: `/CLAUDE.md`, `docs/api-spec.yaml`(`Error` 스키마), `docs/errors.md`(정본).

## 책임

- 공통 에러 응답 미들웨어 (`{ code, message, detail }`, `docs/errors.md`의 코드만 사용)
- 멱등키(Idempotency-Key) 처리 공통 로직
- 페이지네이션 유틸
- PostGIS 좌표 유틸 (직선거리 계산, 13절 — "도보 N분" 근사 표기 규칙 포함)
- `seq` 채번 유틸 (다른 모듈·`realtime`이 공유)

## 넘지 말 것

- `docs/errors.md`에 없는 새 에러 코드를 개별 모듈이 즉석에서 만들지 않는다 — 필요하면 이 표에 먼저 추가(루트 확인 후).
- 거리 계산은 직선거리이고 "도보 N분"은 근사 표기다. 실제 도보 시간처럼 보이는 정밀 계산으로 오인시키는 문구를 만들지 않는다(13절 "표기를 정직하게 하거나 보정계수를 명시").

## 완료 정의

- 에러 미들웨어 + 단위 테스트(코드별 응답 형태)
- 멱등키 처리 단위 테스트(동일 키 재요청 시 같은 응답, 다른 바디면 `IDEMPOTENCY_CONFLICT`)
- 좌표 유틸 단위 테스트(원 겹침 판정 — `recommend`·`shortlist`가 공유해서 쓴다)

## 코드 품질

`docs/code-quality.md` 참고. 여러 모듈이 공유하는 코드라 여기서의 실수는 전 모듈에 퍼진다 — 변경 시 영향 범위를 특히 꼼꼼히 본다.
